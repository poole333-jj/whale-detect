# 卫星遥感鲸鱼检测 Demo

基于 YOLOv8 的卫星遥感影像鲸鱼检测网页应用，Streamlit + Ultralytics 实现。

选图即自动识别，结果带时间戳、可存档、可回溯。

## 功能

- 上传遥感影像自动切片推理（512×512 切片，步长 448）
- 检测框可视化 + 逐目标置信度条
- 识别记录本地存档，关掉页面也能翻回来，支持单条删除
- 侧边栏一键切换「稳妥 / 灵敏」阈值模式
- 可选接入 OpenAI 兼容大模型（DeepSeek / 豆包 / Kimi）做问答与联网检索
- 无 API Key 时走内置离线问答，功能不中断

## 模型

- 骨干：YOLOv8s，输入尺寸 320
- 训练集 508 张 / 验证集 126 张
- mAP50 0.72，mAP50-95 0.31
- 原始影像分辨率 128–149 px，为精度主要制约

## 本地运行

```bash
pip install -r requirements.txt
streamlit run app.py
```

或双击 `启动.bat`（Windows）。
